---

## 🌐 What is NolQu?

**NolQu is a technology ecosystem — not a single project.**

The ecosystem is designed to bring together multiple technologies that can complement each other, ranging from programming languages and compilers to operating systems, system components, and developer tools.

The goal is to build these technologies on a strong and consistent foundation while allowing each component to have its own purpose.
